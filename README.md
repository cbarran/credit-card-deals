# Elite Card Deals

Deals you don't want to miss. A premium, modern web application for discovering and comparing top credit card offers.

![Elite Card Deals Preview](assets/chase-sapphire.png)

## Features

- **Premium UI**: A sleek, dark-themed design with glassmorphism and smooth animations.
- **Dynamic Filtering**: Filter deals by category (Travel, Cashback) or by "No Annual Fee".
- **Responsive Design**: Optimized for mobile, tablet, and desktop viewing.
- **Automated Data**: Powered by a Python-based scraper (experimental).

## Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (with CSS Variables), Vanilla JavaScript (ES6+).
- **Backend/Scraper**: Python 3.10+, BeautifulSoup4, Requests.
- **Design System**: Inter & Outfit Google Fonts, Custom Gradient Palette.

## Getting Started

### Prerequisites
- A modern web browser.
- Python 3.10+ (if you want to run the scraper).

### Installation
1. Clone the repository.
2. Open `index.html` in your browser.

### Running the Scraper
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the scraper:
   ```bash
   python scraper.py
   ```
